### 2.2 全体に通す規則

1. **表示していない設定は使わない。** グラフの種類や軸の種類で入力欄を隠す・無効にするときは、その値を図に使わない（値は消さないので、戻せば効く）。表示している設定どうしが組み合わせとして使えないときは、日本語のエラーで案内する（Phase 4 の「日時の X と対数軸」と同じ）。
2. **列は「系列のデータ元＋列番号」。** エラーバー・塗りつぶし帯・色分けの列は、系列のデータ元の列から選ぶ（行が対応している必要があるため。ほかのファイルの列は選べない）。設定では `__idx__N`。新しい項目は `""` か `__idx__N` だけを受け付ける（列名での指定は受け付けない）。
3. **データを見て決めることは dataprep、コードの文字列は codegen。** 軸の種類（数値・対数・日時・文字列）によって、どの設定が効くかは dataprep が決め、`PlotPlan` に入れる。codegen はそれを文字列にするだけにする。
4. **既定の設定では、生成コードの文面を Phase 4 と同じにする。** 新しい行は、その機能を使ったときだけ書く。
5. **信頼できない文字列は `literal()` / `comment_text()` だけを通す。** 注釈の文字、式、日時の範囲、書式の指定、列名（コメント）も同じ。式（G6・G10）は利用者の文字列をコードに入れず、解釈した木から決まった形のコードを作る（§2.6）。

### 2.3 codegen の広げ方

- **節の番号は `_Builder.section()` が自動で振る**（5b 以降、使うときだけ「注釈」などの節が入る。使わなければ番号は今と同じ）。
- **系列ごとの付属物**（エラーバー 5a、塗りつぶし帯 5b、近似曲線 5b）は、`SERIES_EMITTERS` の各関数から呼ぶ小さな関数に分ける。描く順は「塗りつぶし帯 → エラーバー → 系列本体 → 近似曲線」（系列本体が帯やエラーバーの上に来る）。
- **軸の設定は軸ごとの関数にする。** `_emit_axis_ticks(b, var, which, axis_plan)` のように、Axes の変数名を引数で受ける。G9 では、パネルごとにこれを呼べば済む（`ax` 固定の書き方を増やさない）。
- 手順（`b.step`）を、エラーバー（「系列Nのエラーバー」）と目盛（「X軸の目盛」など）に足す。実行時の失敗を、項目名つきの日本語メッセージにする。
- G7・G8 は `SERIES_EMITTERS` に種類を足す。種類ごとに X の意味が変わる（ヒストグラムは X なし、横棒は値が横軸、箱ひげ図は系列ごとに1つの箱）ので、dataprep が種類ごとの計画を作る（`PlotPlan.kind_plan` のような種類別の小さな dataclass）。

### 2.4 dataprep の広げ方

- `SeriesPlan` に `y_err` / `x_err`（`ErrorPlan | None`）を足す（5a）。5b で `fill`、5c で `color_index` などを足す。
- `PlotPlan` に `axes: AxesPlan` を足す（5a）。`AxesPlan` は `x` / `y` / `y2` の `AxisPlan` を持つ。`AxisPlan` は、その軸の種類（`number` / `log` / `datetime` / `category`）と、実際に効く設定（主目盛・副目盛・書式・反転・範囲）だけを持つ。G9 では `PanelPlan` ごとに `AxesPlan` を持たせる。
- データ由来の警告とエラーは、今までどおり日本語で `PlotPlan.warnings` / `UserError` にする。

### 2.5 「注釈・解析」の区分（5b で作る）

- 位置は「体裁」と「保存」の間（要件 6 章の順）。id は `#sectionAnalysis`、既定で開く（折りたたみの状態は今の仕組みで localStorage に残る）。
- 中身の予定:
  - 注釈（G4、5b）: 「+ 注釈を追加」で、文字・水平線・垂直線・範囲の帯（横・縦）を足す。
  - 近似曲線（G5、5b）: 「+ 近似曲線を追加」で、対象の系列とモデルを選ぶ。系列を削除したら、その近似曲線も消す。
  - 計算した列（G6、5c）: 「+ 列を追加」で、データ元・列名・式を入れる。
  - 任意関数のフィッティング（G10、5d）: 近似曲線のモデルに「任意の式」を足す。
- エラーバー（G1）と系列のスタイル（G3）は系列ごとの設定なので、系列カードに置く。

### 2.6 G3–G10 の概略

**G3（系列のスタイル）**: マーカー形状（`auto` は今の動き: line は点サイズ > 0 なら丸、scatter は丸）、透明度、塗りつぶし帯（`fill_between`。下限・上限の列を系列のデータ元から選ぶ）。並べ替え（↑↓）と複製は JS だけの操作（配列の順番＝描く順。複製は新しい id）。

**G4（注釈）**: 文字（`ax.text`。データ座標か、図の中の割合 0〜1）、水平線・垂直線（`axhline` / `axvline`）、範囲の帯（`axhspan` / `axvspan`）。X の値は、X が日時の軸なら 5a で作る日時の解釈（`pd.Timestamp(...)`）を使う。Y は第2Y軸にも置ける。

**G5（近似曲線）**: `np.polyfit`（線形は1次）。描く範囲は X の最小〜最大を 200 点。式と R² は、生成コードの実行時に係数から作る（`f"y = {coef[0]:.4g}x + …"`。書式は codegen の固定文字列で、利用者の文字列は入らない）。表示先は凡例・図の中・なし。X が日時・文字列の系列は近似できない（日本語のエラー）。

**G6（式で新しい列）**: `eval` も Python の `ast` も使わず、許可した要素だけの小さな文法を自前で解釈する（新しいモジュール `py/mplgui/expr.py`。`pyscript.toml` に追加）。

- 文法: 数値、列の参照、`+ - * /`、`**`（`^` も可）、括弧、単項マイナス、許可した関数だけ。
  - 要素ごとの関数: `abs` `sqrt` `exp` `log`（自然対数）`log10` `sin` `cos` `tan`
  - 集計（列 → 1つの値）: `min` `max` `mean` `median` `std` `first` `last`
  - 系列の処理: `rolling_mean(式, 窓の幅)`（移動平均。窓の幅は整数の定数）、`diff`、`cumsum`
- 列の参照は `[N]`（画面の「列名 [N]」の N。0 始まり）。要件の例（`B*1000`、`B/C`）に合わせて、Excel の列記号（`A` = `[0]`、`B` = `[1]` …）も使えるようにする。列名での参照は受け付けない（同名の列を区別できないため）。
- 長さ（200 文字まで）と入れ子の深さ（30 まで）に上限を設ける。数値は有限の値だけ。
- 解釈した木からコードを作る。数値は `literal()`、列は `pd.to_numeric(df.iloc[:, N], errors="coerce")`、関数は決まった形（`np.sqrt(…)`、`(…).rolling(5, center=True).mean()` など）。利用者が書いた式の文字列は、`comment_text()` を通してコメントにだけ入れる。0 で割った結果（±inf）は NaN にする。
- 正規化・オフセット・移動平均は、式の入力欄に雛形を入れるボタンにする（例: `[1] / max([1])`、`[1] - first([1])`、`rolling_mean([1], 5)`）。
- 新しい列は、そのデータ元の DataFrame の末尾に足す（列番号 = 元の列数 + 順番）。系列の X・Y の選択肢にも出る。dataprep も同じ木を pandas で評価して、数値にならない値の警告や列の範囲外を確かめる。

**G7–G9（グラフの種類とサブプロット）**:

- グラフの種類は今と同じく図全体で1つ（`plot.type`）。`SERIES_EMITTERS` に `step`（`drawstyle="steps-post"` など）、`barh`、`barStacked`、`hist`、`scatterColor`（第3列で色分け。全系列で色の範囲とカラーバーを共有）を足す。
- 横棒では、物理的な軸の設定をそのまま使う（X軸の設定＝横軸＝値の軸、Y軸の設定＝縦軸＝カテゴリ）。軸ラベルの自動の値だけ入れ替える。
- サブプロット（G9）: `fig, axs = plt.subplots(行, 列, squeeze=False)`。系列ごとにパネルを選ぶ。軸の目盛・スケールの設定は全パネル共通（`axes`）で、タイトルと軸ラベルはパネルごとに上書きできる（`panels`）。グラフの種類は全パネル共通。(a)(b) のラベルは `ax.text(…, transform=ax.transAxes)` で付ける。第2Y軸の変数名は、パネルごとに `ax_a2` のようにする（§2.3 の「Axes の変数名を引数で受ける」形で実現する）。

**G10（任意関数のフィッティング）と U5（scipy）**: 要件 4.2（生成コードは pandas・matplotlib・numpy だけ）とぶつかるので、案を3つ挙げる。

### 2.7 性能の見込み（10,000 行 × 5 系列、設定変更 → 再描画。現状 465 ms）

- **G1 のエラーバーは `ax.errorbar` を使うと間に合わない。** ブラウザで実測すると（編集モードで同じ図を描いて比較、N=5）、`ax.errorbar` は1系列あたり 10,000 本の線分を別々の図形として作るので、5 系列で **+約 1,040 ms**（合計 約1.5 秒）になる。各系列の縦線を NaN で区切った1本の線にまとめ、端の横線を点の記号（`marker="_"`）で描く方法なら **+約 150 ms**（合計 約0.6 秒）で、見た目は `ax.errorbar` と同じになる。5a はこの方法を推奨する（§3.2）。X・Y の両方向でも 1 秒以内の見込み。
- G2（目盛）は、目盛の数を 100 本までに抑えるので、ほぼ影響なし。間隔が小さすぎる指定をそのまま描くと、3,000 本の目盛で 1.6 秒、100 万本では止まる（実測）ため、上限は必須。
- G3 の塗りつぶし帯は多角形1つなので軽い。G5 の `np.polyfit`（10,000 点）は数 ms。G7 のヒストグラム・色分け散布図も今の散布図と同程度。G8 のバイオリン図は密度推定があるので 5d で計測する。G9 は `tight_layout` がパネル数に比例して重くなる。G10 は初回の scipy の読み込み（数秒）が別にかかる。

### 3.2 G1 エラーバー

**指定のしかた**: 系列ごとに、Y 方向と X 方向をそれぞれ「なし / 固定値 / 列」から選ぶ。既定は上下（左右）で同じ値。「上下で別の値」にすると、上（+）と下（−）を別に指定できる。列は系列のデータ元から選ぶ（§2.2）。列の値は「誤差の大きさ」（0 以上）として扱う。

**描き方**:

- line / scatter: 系列本体の直前に、エラーバーを描く関数 `draw_error_bars` を呼ぶ。縦線（X 方向なら横線）を NaN で区切った1本の線にまとめ、端の横線（縦線）を点の記号で描く。見た目は `ax.errorbar(..., capsize=…)` と同じで、10,000 点でも速い（§2.7）。この関数は、エラーバーを使うときだけスクリプトの冒頭（import の後）に定義する。pandas・matplotlib・numpy だけを使い、「`ax.errorbar` と同じ図を、点が多くても速く描くための関数」とコメントを付ける。
- bar: `ax.bar(..., yerr=…, capsize=…, ecolor="black")`（棒グラフの標準の書き方。棒の本数は多くないので速さは問題にならない）。X 方向は使わない（入力欄を隠す）。複数系列の棒は `bar_data` に誤差の列を足す。
- 色は系列の色（棒グラフは黒）。線幅は系列の線幅。
- 重なり順: 系列本体を上にする（scatter のときはエラーバーの `zorder` を 1 にして、点を上に描く）。
- 第2Y軸の系列は `ax2` に描く。
- 凡例: 今までどおり系列の線・点・棒だけを出す（エラーバーの記号は出さない）。系列の描き方を変えずに済み、エラーバーの有無で凡例が変わらないため。

**データの扱い**:

| 場合 | 扱い |
|---|---|
| 誤差の列が空欄 | その点のエラーバーだけ描かない（警告なし） |
| 数値にできない値（A7） | その点のエラーバーだけ描かない。系列ごとに件数と例を警告する（桁区切り・小数点のヒントも今と同じく付ける） |
| 負の値 | その点のエラーバーだけ描かず、件数を警告する（誤差の大きさは 0 以上のため）。生成コードでは `y_err = y_err.where(y_err >= 0)` で NaN にする |
| 系列の点が欠けている行（`ok` が偽） | 点を描かない行のエラーバーも描かない |
| 対数軸で下端が 0 以下 | エラーではない。下端は軸の下端まで伸びる（matplotlib の既定の `clip`。軸の範囲は正の値だけで決まる） |
| X が日時・文字列の系列で X 方向を指定 | 日本語のエラー（「系列1: X が日時（文字列）の列のときは、X 方向のエラーバーは付けられません」） |
| 固定値・列が未入力 | 日本語のエラー（`field` は「系列1のY誤差」など） |
| データ元を替えた | X・Y と同じく、誤差の列を空に戻す（方式はそのまま。列を選び直すよう日本語のエラーで案内する） |

**生成コードの例**（line、Y 方向・列・上下で同じ）:

```python
# エラーバーを描く関数（ax.errorbar(x, y, yerr=…, capsize=…) と同じ見た目。点が多くても速く描ける）
def draw_error_bars(ax, x, y, lower, upper, *, direction, color, linewidth, capsize, zorder=2):
    ...  # 区切りに NaN を入れた1本の線（縦線または横線）と、両端の短い線（点の記号）を描く

# 系列1: X = 時間 [0]、Y = 温度 [1]
x = df.iloc[:, 0]
y = pd.to_numeric(df.iloc[:, 1], errors="coerce")  # 数値にできない値は NaN にする
ok = x.notna() & y.notna()  # X か Y が欠けている行は描かない
y_err = pd.to_numeric(df.iloc[:, 3], errors="coerce")  # Y の誤差: 標準偏差 [3]（数値にできない値は NaN）
y_err = y_err.where(y_err >= 0)  # 負の値は NaN にする（その点のエラーバーは描かない）
draw_error_bars(ax, x[ok], y[ok], y[ok] - y_err[ok], y[ok] + y_err[ok], direction="y", color="#FF4B00", linewidth=2.0, capsize=3.0)
ax.plot(x[ok], y[ok], color="#FF4B00", linewidth=2.0, linestyle="solid", label="温度")
```

上下で別の値なら `y_err_plus` / `y_err_minus` の2列、固定値なら `y[ok] - 0.2, y[ok] + 0.5` のように書く。

### 3.3 G2 目盛

軸ごと（X・Y・第2Y）に、次を設定できるようにする。

| 設定 | 数値の軸 | 対数軸 | 日時の X | 文字列の X（line / scatter）・棒グラフの X |
|---|---|---|---|---|
| 主目盛の間隔 | `ticker.MultipleLocator(間隔)` | 使わない（入力欄を無効にする。主目盛は 10^n ごと） | 整数 + 単位。`mdates.YearLocator(base=n)` / `MonthLocator(interval=n)` / `DayLocator(interval=n)` / `HourLocator` / `MinuteLocator` / `SecondLocator` | 「何個おきにラベルを出すか」（整数）。`MultipleLocator(n)`、複数系列の棒は `tick_step = n` |
| 副目盛 | 自動・表示・なし。表示のとき分割数（2〜10、空欄は自動）で `AutoMinorLocator(n)` | 自動・表示・なし（表示は 2〜9 × 10^n。分割数は使わない） | 数値の軸と同じ | 使わない（隠す） |
| ラベルの書式 | 自動 / 小数（`FormatStrFormatter("%.2f")`）/ 指数表記（`"%.1e"`）/ 10^n 表記（`ScalarFormatter(useMathText=True)` と `set_powerlimits((0, 0))`。軸の端に ×10^n をまとめて書く） | 自動（10^n）/ 小数 / 指数表記 / 10^n（`LogFormatterSciNotation`）。自動以外のとき、副目盛の数字は消す | 使わない（Phase 4 の「日時の表示書式」を使う） | 使わない |
| 軸の反転 | `ax.invert_xaxis()` など。範囲を指定していても使える | 同左 | 同左 | 同左 |

- **上と右の枠線**（`plot.spines`）: `ax.spines["top"].set_visible(False)` など。第2Y軸があるときは、`ax2` の上の枠線も消す。第2Y軸があるときは右の枠線（第2Y軸の線）は消せないので、チェックボックスを無効にして、そのことを補足に書く。
- **既存のグリッドとの関係**: 「副目盛線を表示」は今までどおり「副目盛の位置に線を引く」。副目盛が「自動」の軸は今の動きのまま（副目盛線を表示するときだけ副目盛を出す。対数軸は副目盛線を表示しないとき副目盛を消す）。「表示」「なし」を選んだ軸は、副目盛線の設定にかかわらずそれに従う（「なし」で副目盛線を表示すると、その軸には副目盛線が出ない）。今の `ax.minorticks_on()` は軸ごとの副目盛の指定を上書きしてしまう（実測）ので、軸ごとに指定がある場合は軸ごとの書き方にする。すべて「自動」なら、生成コードは今と同じ文面。
- **目盛が多すぎるとき**: dataprep が、データの範囲（指定した範囲、エラーバーの端を含む。棒グラフは 0 を含む。余白 5% を足す）と間隔から、主目盛の本数を見積もる。100 本を超えたら日本語のエラーにする（「X軸の主目盛の間隔が小さすぎます（目盛が約N本になります。100本まで）。間隔を大きくするか、空欄（自動）にしてください。」、`field` は「X軸の主目盛の間隔」）。文字列の X はカテゴリの数、日時は期間を単位の長さ（月は 30.44 日、年は 365.25 日）で割って見積もる。副目盛の分割数は 10 までなので、副目盛も最大で約 1,000 本（matplotlib が警告を出す `MAXTICKS` の目安）に収まる。
- **整数でないといけない場合**: 日時の X と文字列の X の主目盛の間隔は整数。整数でなければ日本語のエラー。
- **0.1 刻みの誤差**: `MultipleLocator(0.1)` の目盛の位置は 0.30000000000000004 のような値になるが、ラベルは「自動」でも「小数1桁」でも 0.3 と出る（実測）。テストで、範囲の端（0 と 1.0）が欠けないことと、ラベルの文字列を確かめる。

**生成コードの例**:

```python
ax.xaxis.set_major_locator(ticker.MultipleLocator(0.5))  # X軸の主目盛: 0.5 ごと
ax.xaxis.set_minor_locator(ticker.AutoMinorLocator(5))  # X軸の副目盛: 主目盛の間を 5 等分
ax.xaxis.set_major_formatter(ticker.FormatStrFormatter("%.2f"))  # X軸の数字: 小数 2 桁
ax.invert_yaxis()  # Y軸を反転する（上が小さい値）
ax.spines["top"].set_visible(False)  # 上の枠線を消す
```

### 3.4 X が日時の列のときの X 軸の範囲指定（5a で扱う提案）

- Phase 4 では「X が日時のときは X 軸の範囲を指定できない（エラー）」にした。G2 で日時の目盛の間隔を扱い、5b の注釈でも日時の座標が要るので、5a で日時の範囲指定を入れる。
- X が日時の列のときは、数値の最小値・最大値の欄（`#xMin` / `#xMax`）を隠し、日時の欄（`#xDateMin` / `#xDateMax`、文字の入力欄、例「2026-01-31 12:00」）を出す。X が日時でないときは逆。隠した欄の値は使わない（§2.2 の規則）。
- 生成コード: `ax.set_xlim(left=pd.Timestamp("2026-01-01 00:00:00"), right=pd.Timestamp("2026-02-01 00:00:00"))`。文字列は settings で解釈して正規化した値を `literal()` で書く。
- 対数軸との組み合わせは、今までどおりエラー。
- これに伴い、Phase 4 のテスト（単体: 日時の X と数値の範囲でエラーになること。E2E: `test_datetime.py` の X の範囲指定のエラー）を、新しい動き（日時で範囲を指定できる・数値の範囲は使わない）に合わせて書き換える。

### 3.5 画面
